# data from RAND corporation on historical record of state legislatures actions on firearms control

data from RAND corporation on historical record of state legislatures
actions on firearms control

## Usage

``` r
data(gunleg)
```

## Format

data.frame

## Note

This data.frame has dates, statute text extracts, and interpretive
categories. The dataset was retrieved from [RAND corporation
site](https://www.rand.org/pubs/tools/TLA243-2-v4.html)
