# data from CDC on homicide rates by state by year

data from CDC on homicide rates by state by year

## Usage

``` r
data(cdcmurd)
```

## Format

data.frame

## Note

This data frame describes murder rates over time in the 50 states and
D.C. The dataset is available at
<https://www.cdc.gov/nchs/state-stats/deaths/homicide.html>.
